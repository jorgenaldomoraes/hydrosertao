# 🌊🌵 HydroSertão

Sistema embarcado de irrigação inteligente voltado para a agricultura no semiárido nordestino.

---

## 📌 Descrição

O HydroSertão é um sistema desenvolvido com microcontrolador RP2040 (BitDogLab) capaz de monitorar condições ambientais e acionar automaticamente a irrigação, otimizando o uso da água.

O projeto integra sistemas embarcados e Internet das Coisas (IoT), permitindo controle local e monitoramento remoto.

---

## 🎯 Objetivos

- Monitorar a umidade do solo (simulada)
- Controlar automaticamente a irrigação
- Fornecer feedback visual ao usuário
- Implementar segurança com interrupção
- Enviar dados para monitoramento remoto (IoT)

---

## ⚙️ Funcionalidades

- Leitura do sensor interno (ADC)
- Controle automático da irrigação
- Botão de emergência (interrupção)
- Interface via display
- Feedback com LEDs e buzzer
- Comunicação via Wi-Fi
